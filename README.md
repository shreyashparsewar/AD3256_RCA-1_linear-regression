# Unit 1 – House Price Prediction

## Project Overview
This project focuses on predicting house prices using a housing dataset and machine learning regression techniques. It covers data preparation, exploratory data analysis, model training, and evaluation.

## Objectives
- Understand and explore the housing dataset.
- Identify input features and the target variable.
- Clean and prepare data for machine learning.
- Train a regression model to predict house prices.
- Evaluate the model's performance.

## Dataset
- **Dataset:** Housing / House Price Dataset
- **Target Variable:** House Price
- **Input Features:** Housing-related attributes such as area, rooms, location, and other property details.

## Workflow
1. Import required Python libraries.
2. Load the housing dataset.
3. Explore dataset structure and data types.
4. Check missing values and duplicate records.
5. Perform Exploratory Data Analysis (EDA).
6. Select input features (X) and target variable (y).
7. Split the dataset into training and testing sets.
8. Train the regression model.
9. Predict house prices.
10. Evaluate the model using regression metrics.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## How to Run
1. Open the notebook in Google Colab.
2. Load the housing dataset.
3. Run the notebook cells step by step.
4. Observe the predictions and evaluation results.

## Conclusion
This project demonstrates the application of machine learning regression techniques to predict house prices using housing data.
